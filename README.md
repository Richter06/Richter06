# 🏆 Projetos em destaque

Selecionados pela combinação de **complexidade, arquitetura, variedade técnica e problemas resolvidos**.

### 01 · [Rouxinol](https://github.com/Richter06/rouxinol)
**Experiência digital comercial • React + 3D**

Projeto mais recente e experimental, combinando **React, Vite, Three.js, React Three Fiber, Drei, Motion, GSAP, HLS.js e WebGL**. Experiência narrativa com modelos 3D, scroll-driven interactions, mídia, componentes independentes e atenção a performance.

### 02 · [FangyScraper](https://github.com/Richter06/FangyScraper)
**Web crawler • análise estática • segurança**

Ferramenta Node/Express que recebe uma URL e analisa **HTML, CSS, JavaScript, recursos e indicadores de segurança**, usando Cheerio, Acorn/acorn-walk, PostCSS e ipaddr.js, com validações, limites e analisadores modulares.

### 03 · [Little Bee](https://github.com/Richter06/paginaDeArtesVisuais)
**Full-stack • autenticação • CRUD • arquivos**

Aplicação de arte com área pública e administrativa, construída com **Node.js, Express, Supabase, Multer, Express Session, Helmet e rate limiting**. Inclui autenticação, CRUD, upload, banco, Storage e integração com Cloudflare.

### 04 · [Alien Terminal](https://github.com/Richter06/AlienTerminal)
**React • simulação • grafos • pathfinding**

Jogo de sobrevivência baseado em turnos, com mapa em grafo, movimentação do Alien, RADAR, perseguição, pathfinding, bloqueios, eventos e sistema de ventilação com estados diferentes. Construído com **React, Vite, JavaScript, Hooks e SVG**.

### 05 · [Pokédex React](https://github.com/Richter06/pokedexReact)
**React • API • 3D**

Projeto de aprofundamento em React usando **PokéAPI, componentização, props, hooks, estados de loading/erro** e uma Pokébola 3D com **Three.js / React Three Fiber / Drei**.
